# ネットワークの基本メモ

## ループバック

`127.0.0.1`は自分のPC自身を指すIPv4のループバックアドレス。`localhost`も通常は`127.0.0.1`またはIPv6の`::1`へ解決される。

```text
PCで http://127.0.0.1:8080
  → 同じPCで待ち受けるAPIへ届く

スマホで http://127.0.0.1:8080
  → スマホ自身を指す
```

## 待ち受けアドレス

```text
127.0.0.1:8080  : PC自身からの通信だけを受ける
192.168.x.x:8080: 指定したLAN側IPで届く通信を受ける
:8080           : PCが持つローカルアドレスで8080番を待ち受ける
```

`192.168.x.x`は、家庭内などのローカルネットワークでPCへ割り当てられるIP。接続先や再接続で変わり得るため、APIコードへ固定で書かず、今回は`Addr: ":8080"`を使う。

## PCのLAN側IPを確認する

WindowsのPowerShellで次を実行する。

```powershell
ipconfig
```

現在利用しているWi-Fiまたはイーサネットの項目にある`IPv4 Address`が、同じ家庭内ネットワークのスマホから接続するときに使うPCのIP。

```text
IPv4 Address : 192.168.11.2
Default Gateway : 192.168.11.1
```

この例では、スマホから`http://192.168.11.2:8080/health`へ接続する。

## 家庭内ネットワークでのIP割り当て

Wi-Fiは端末とルーターを無線でつなぐ方式。PCやスマホにIPを割り当てる役は、通常は家庭内ルーターのDHCP機能が担う。

```text
ルーター（192.168.11.1）
  ├─ PCへ 192.168.11.2 を割り当てる
  └─ スマホへ 192.168.11.x を割り当てる
```

DHCPで割り当てられたIPは、ルーターへの再接続などで変わることがある。

## 待ち受けと外部公開は別

`Addr: ":8080"`は、APIがPCへ届いた8080番通信を受ける設定であり、世界中からのアクセスを許可する設定ではない。

```text
スマホ → 同じWi-Fiのルーター → PC → Go API
外部インターネット → 自宅ルーターで通常はPCへ転送されない
```

Windows FirewallやルーターのNAT・ポート転送が、通信をPCまで通すかを別途判断する。
